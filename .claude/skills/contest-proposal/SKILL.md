# 공모전 제안서 Skill

이 Skill 은 **형식과 규칙**만 담는다. 무엇을 제안할지는 메인 에이전트가 정하고,
조사·그림·심사는 서브에이전트(`.claude/agents/`)가 맡는다.

## 1. 골조 (순서 고정)

1. **제목** — `『<기관> <대상> 개선 아이디어 제안서』`
2. **제안서명** — `( 제안서명: <짧은 브랜드명> )`. 영문 병기 가능. 예: `PNU 커먼스(Commons)`
3. **한 줄 요약** — 숫자 하나 이상 + 핵심 장면 하나. 70자 안팎.
   예: "본식은 110분에서 65분으로 줄이고, 대운동장에서 졸업생 전원이 이름이 불리며 학위를 받는다"
4. **현행 vs 개선 비교표** — 바꾸는 대상(식순·절차·비용)을 행으로, `현행 | 개선 | 내용 | 비고`.
   합계 행 필수. 바꾸지 않는 항목도 "유지" 로 남겨 전체를 보여준다.
5. **새 프로그램 개요** — 한 문단 + 시간표 표(`시간 | 순서 | 장소`).
6. **세부 운영** — `1)` `2)` 소제목 + `-` 글머리. 소제목마다 시간대를 괄호로.
7. **실행 조건** — 예산 범위, 담당 주체, 리스크와 **대체안**.
8. **기대 효과** — 3개 이하. 측정 가능한 것 우선.

공고가 별도 목차를 요구하면 공고 목차를 따르고, 위 골조는 그 안에서 재배치한다.

## 2. 문체 규칙

- 명사형 종결. "~함", "~운영", "~대체". "~합니다" 금지.
- **숫자로 말한다.** "단축" 대신 "110′ → 65′". 시간은 `′`(분), 시각은 `09:30-11:00`.
- **삭제·축소에는 반드시 대체 수단을 붙인다.** "학사보고 삭제 → 전광판 자막·식순지로 대체".
- **추정치는 ※ 주석으로 범위를 밝힌다.** "※ 35분은 추정치, 박사 학위자 수에 따라 25~40분".
- **실현이 막힐 수 있는 요소는 대체안을 같은 자리에 쓴다.** "드론 승인이 어려우면 스탠드 상단 고소 촬영".
- 운영 주체를 적는다. "(총학생회·생활협동조합 운영)".
- 형용사 최소화. "감동적인", "획기적인" 금지 — 장면을 묘사해서 감동을 보여준다.
- 확인하지 않은 사실(인원, 예산, 규정)을 단정하지 않는다. 출처가 research.md 에 없으면 "추정" 표기.

## 3. proposal.json

`scripts/build_docx.py` 의 입력. 블록 종류:

| type | 필드 | 비고 |
|---|---|---|
| `paragraph` | `text` | `**굵게**` 지원 |
| `subheading` | `text` | `1) 오전 축제 (09:30-11:00)` |
| `bullets` | `items` | `-` 글머리 |
| `note` | `text` | ※ 주석, 작은 글씨 |
| `table` | `columns`, `rows`, `total`(선택), `widths`(선택, cm), `merge_first_col`(선택) | 첫 열이 빈 칸이면 위 칸과 병합 |
| `figure` | `path`, `caption`, `width_cm`(선택) | proposal.json 기준 상대 경로 |
| `callout` | `text` | 회색 박스 강조 |

최상위: `contest`, `title`, `name`, `summary`, `sections[{heading, blocks[]}]`, `author`(선택).
예시는 `examples/graduation/proposal.json`.

## 4. 빌드

```bash
python .claude/skills/contest-proposal/scripts/build_docx.py <proposal.json> <out.docx>
# 미리보기(심사 에이전트가 보는 용도). LibreOffice 필요
python .claude/skills/contest-proposal/scripts/preview.py <out.docx>
```

`preview.py` 는 PDF 와 페이지별 PNG 를 `out.docx` 옆에 만든다.
그림(SVG)은 `scripts/render_svg.py` 로 PNG 로 바꿔서 `figure` 블록에 넣는다.
