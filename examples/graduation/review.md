## 반드시 고칠 것

1. **"본식 110′ → 77′" 명칭 오류 (한 줄 요약, 1쪽 비교표 합계 행, 4쪽 기대 효과)**
   110′는 식전 20′를 포함한 오전 행사 전체이고, 본식은 90′ → 67′임. 그림 1·2는 "오전 행사 77′"로 맞게 씀.
   - 한 줄 요약 → "오전 행사는 110′에서 77′로 줄이고, 오후 단과대학별 수여식에서 사전 신청한 학사·석사 졸업생 전원(대상 최대 약 4,300명)의 이름을 부름"
     (원문 "학사·석사 4천여 명 전원의 이름을 부름"은 사전 신청자만 호명한다는 본문과도 어긋남)
   - 비교표 합계 행 내용 → "오전 행사 33′ 단축(식전 10′ + 본식 23′) + 오후 단과대학별 수여식 신설"
   - 기대 효과 2번 → "오전 행사 시간 단축: 110′ → 77′ (33′, 30% 단축. 본식만 보면 90′ → 67′)"

2. **1쪽 "1. 현황과 문제" 비율 계산 오류**
   60′/90′ = 67%이며, 55%는 전체 110′ 기준임.
   - "본식 90′ 중 학위수여가 60′(약 55%)를 차지하나" → "전체 110′ 중 학위수여가 60′(약 55%, 본식 90′ 기준 약 67%)를 차지하나"

3. **네임콜 수여식 시간 산술 불일치 (3쪽 세부 운영 2), 그림 2·3, 1쪽 비교표 오후 행)**
   평균 290명 × 1인 8초 = 약 39′인데 식순은 "호명 수여 30′ 내외, 총 40′"로 적음. 2회차 기준 400명이면 400×8초 = 53′로 60′ 슬롯(13:30/14:30)을 넘김.
   - 식순 → "식순: 학장 인사 3′ → 호명 수여 40′ 내외(1인 약 8초) → 학과 대표 한마디 3′ → 단체 사진 4′ (회당 50′ 내외)"
   - 회차 기준 → "인원 300명 초과 단과대학은 학부(과)별 2회차로 분리 (13:30 / 14:30 시작)"
   - ※ 주석 → "※ 단과대학별 50′ 내외는 추정치. 학사·석사 약 4,300명을 단과대학 약 15개(가정)로 나누면 평균 약 290명, 1인 약 8초 호명 기준 약 39′. 단과대 규모에 따라 회당 20~50′."
   - 비교표 오후 행 개선 칸 "40′ 내외" → "50′ 내외", 그림 2 "단과대별 40′ 내외"·"400명 초과" 와 그림 3 식순 막대(30′ → 40′)도 같이 수정.

4. **서울대 사례를 현재 시제로 단정 (1쪽 "1. 현황과 문제" 세 번째 글머리)**
   research.md 근거는 2016년 기사뿐이며 현재(2026) 운영 방식은 미확인.
   - → "규모가 비슷한 국립대(서울대, 2016년 졸업생 약 4,970명)는 2016년 학위수여식에서 전체식 뒤 단과대학별 수여식을 이어 운영 (현재 운영 방식은 미확인)"

5. **소제목이 쪽 끝에 홀로 남음 (2쪽 하단 "4. 세부 운영", 3쪽 하단 "5. 실행 조건 / 1) 예산 범위 (추가분)")**

## 고치면 좋은 것

- **가족 대기 부담 주장과 일정 충돌**: 기대 효과 "가족 대기 부담 감소"라 했으나 일정은 09:00-17:00으로 늘고 10:57-13:30 공백 2.5시간이 생김. → "오전 행사 33′ 단축. 오후 수여식은 선택 참석이며, 사이 시간(11:00-13:30)은 사진·점심 구역으로 운영" 으로 바꾸거나 오후 시작을 12:30으로 당기는 안 검토.
- **예산 범위 폭 축소**: 200~2,650만원은 판단 근거로 약함. "단과대 강당 기존 장비 사용 시 약 200~500만원 / 외부 대여 시 최대 2,650만원"처럼 조건별 두 줄로 분리.
- **전광판 보유 여부 미확인**: "전광판 자막" → "전광판(미보유 시 스크린) 자막". 경암체육관 설비는 research.md에 없음.
- **학위수여 40′ 추정에 학사 수석 인원 미반영**: ※ 주석에 "학사 수석 약 ○명 포함 시 +○′" 범위 추가.
- **차별성 보강**: 이름 카드 방식이 스탠퍼드 학과별 ceremony 방식을 옮긴 것임을 한 줄로 밝히고, 부산대만의 요소(꽃 노점 지정 구역, 단과대 포토존)를 요약 근처로 끌어올림.
- **그림 내 주석 글씨**: 그림 1·3 하단 ※ 주석이 본문 대비 매우 작음. 그림 아래 본문 ※ 주석과 중복이므로 그림 안에서는 삭제하고 본문 주석으로 대체.
- **제출물 누락 확인**: 공고는 [양식1] 참가신청서(제안서명 + 요약설명)를 별도로 요구함. 제안서에는 제안서명·요약이 있으나 신청서 파일은 따로 준비 필요.
- **잡코리아 70.3% 등 웹 수치**: research.md 상 원문 미대조 상태. 제출 전 원문 확인.
